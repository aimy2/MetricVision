# Objectives

- Calibrate the smartphone camera using at least 20 checkerboard images.
- Collect and annotate at least 70 original card photographs.
- Compare U-Net, DeepLabV3+ and Mask R-CNN.
- Detect a known-size ArUco reference marker.
- Measure card width and height in millimetres.
- Validate measurements against a physical ruler.
- Report segmentation metrics, measurement errors and limitations.
